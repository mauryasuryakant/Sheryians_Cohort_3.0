# Sheryians Cohort 3.0

Assignments, practice files, and projects completed during Sheryians Coding School Cohort 3.0.

## Repository Details

This repository contains:

* Daily assignments
* Practice exercises
* Mini projects
* Layout recreations
* HTML and CSS experiments
* Concepts learned during the cohort

## Topics Covered

* Semantic HTML
* Forms and inputs
* CSS selectors
* Box model
* Positioning
* Flexbox
* CSS Grid
* Responsive design
* Animations and transitions

## Running the Projects

Clone the repository:

```bash
git clone https://github.com/mauryasuryakant/Sheryians_Cohort_3.0.git
```

Open any project folder and run the HTML file in a browser.
